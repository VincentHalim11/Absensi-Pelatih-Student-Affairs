# Absensi-Pelatih-Student-Affairs
Proyek magang selama di student affair yaitu membuat sistem absensi dengan menggunakan appscript dengan HTML, CSS dan JS

untuk menggunakan sistem ini diperlukan : 
 - Gsheet

kemudian membuat 6 sheets yang terdiri dengan nama berikut : 
 - AllowedUsers
 - Log Absensi
 - UKM
 - CLUB
 - Initations
 - HistoryLaporan
